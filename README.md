# CardingCalc

CardingCalc is an educational web application for Textile Engineering students.

## Features
- Cylinder surface speed calculation
- Feed lap linear density calculation
- Draft calculation

## Built With
- Python
- Streamlit

## How to Run
Install the requirements:

`pip install -r requirements.txt`

Run the app:

`streamlit run app.py`

## Note
Check the formulas and units taught in your course before using calculated results.
